# Operator/legal review required before publication

State: DRAFT — not approved/published. Version 2026-11-15-draft.

The public `/privacy` page describes current implementation facts and explicitly labels missing publication and controls. The authenticated Privacy Center derives policy/provider/retention status from backend configuration and database records; its inventory describes implemented storage paths.

Before publishing an actual privacy notice, the responsible operator must provide legal entity and contact, user/jurisdiction scope, processing purposes/basis, retention/deletion/backup handling, rights-response procedures, shared Auth/account lifecycle, subprocessors and actual account-tier contracts, international transfer/region details, security incident contact and effective/version/approval record. Verify OpenAI/Gemini data terms against the configured account/model/features before stating training or retention promises.

Request submission is implemented; fulfillment, case management and automatic purges are not. Do not publish a notice claiming these operate automatically. Existing shared-project profile creation must be reviewed. This file is a technical review checklist, not legal advice or a declaration of GDPR/DPDP/HIPAA/SOC 2 compliance.
