# Markloom Premiere
Approved mockup direction: giant layered editorial typography, three glass product panels, liquid ribbon and 88 GPU-rendered fragments. Scroll brings each product panel forward and morphs the ribbon and fragment positions. Pointer changes glass highlights and tilt. The product art is illustrative, not an actual approval. Public links and chapter examples remain accessible. Mobile and reduced motion keep static art and native navigation. CSS approximates glass edges; WebGL uses a procedural reflection map and partial transmission, not native Apple Liquid Glass or true refraction of HTML. Browser CI pinned to Ubuntu 24.04 because existing Playwright does not support Ubuntu 26.04. No new package, backend, or database change. Review actual desktop/mobile preview before merging.
