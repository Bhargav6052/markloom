# Markloom Signature

Approved charcoal / dusty purple / gold direction. The new first viewport is a brand reveal with giant background markloom typography and a distinct two-frame, bevelled, procedurally modelled 3D logo. Cursor movement anywhere in the hero controls yaw, pitch and horizontal/vertical position; after 700ms without motion, yaw advances continuously at 0.19 radians/sec (gentle) or 0.35 (full). The animation pauses off-screen or when the tab is hidden, caps pixel ratio at 1.5 and uses a static SVG on mobile, reduced motion, or WebGL failure. The previous three-stage product narrative remains below the hero; native scrolling and a progressive scroll-timeline entrance avoid scroll hijacking. Buttons lift on hover and compress to 95% on press, with reduced-motion opt-out. Uses system typography; no third-party fonts or new packages. CSS and procedural environment lighting approximate liquid glass; no native Apple API or literal screenshot reproduction. Gold is a small accent. No backend, auth, schema, or role changes. Review actual browser screenshots and user Mac performance before merging.
