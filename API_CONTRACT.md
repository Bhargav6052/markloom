# Implemented API contract

OpenAPI is generated by FastAPI at `/openapi.json`; interactive `/docs` is available in development. This repository preserves its existing `/api` surface instead of promising an unimplemented `/api/v1` catalog.

All organization operations require a verified bearer session and current membership. UUID inputs are validated. Browser route guards supplement server/DB authorization.

| Method | Route | Behavior |
| --- | --- | --- |
| GET | `/health` | Process/configuration status, not dependency connectivity |
| GET | `/ready` | Live Auth/DB reachability and worker heartbeat, 503 when not ready |
| GET | `/api/me` | Verified identity and current memberships/organizations |
| POST | `/api/organizations` | `{action: create_org or accept_invite, data: {...}}` |
| GET | `/api/orgs/{org_id}/{table}` | Allowlisted tenant records, newest first, max 1,000; RLS applies |
| POST | `/api/orgs/{org_id}/command` | `{action, data}`; transactional role/ownership/state checks |
| POST | `/api/orgs/{org_id}/uploads` | Multipart file, purpose and classification; bounded extraction/private registration |
| GET | `/api/orgs/{org_id}/documents/{id}/download` | Authorized original binary, attachment disposition |
| POST | `/api/orgs/{org_id}/analyze` | `{version_id, idempotency_key, external_consent:false}`; 202 persisted job; no synchronous fake result |
| POST | `/api/orgs/{org_id}/privacy/preflight` | `{version_id}`; actual classes, provider, policy revision, reasons and allowed state |
| GET | `/api/orgs/{org_id}/privacy/status` | Actual config, data map, unpublished notice/retention status |
| POST | `/api/orgs/{org_id}/privacy/policy` | Admin only; `{allow_public, allow_internal}`; versioned/audited policy |
| POST | `/api/orgs/{org_id}/privacy/requests` | Member `{kind: export or deletion}`; records requested status only |

Record resources: memberships, invites, documents, assets, sources, source_versions, content, content_versions, analysis_runs, issues, dependencies, review_requests, comments, decisions, passports, fact_changes, impacts, notifications, audit_log, correction_decisions, ai_policies, processing_events, privacy_requests and analysis_jobs. Private requests are visible only to their requester or organization admin; notifications only to their intended member.

Command actions: invite, set_role, approve_asset, save_source, impact_preview, activate_source, retire_source, create_content, revise_content, correction_decision, submit, comment, decide, read_notification. `register_document` is rejected in favor of the trusted upload endpoint. Source/role/asset maintenance is admin-only. Content changes/analysis require creator ownership or admin. Decisions require an independent manager or assigned reviewer; never the content owner or AI. SQL enforces current content/evidence and transaction boundaries.

Draft classification is `metadata.classification`; source classification is `config.classification`; upload classification is multipart form data stored in document metadata. Missing values default confidential in processing decisions. Changing classification requires saving a new version.

Errors use FastAPI `{detail: string or validation list}`; request IDs and no-store headers are added by middleware. Statuses include 400/422 validation, 401 auth, 403 forbidden, 404 resource, 409 conflict, 413 size, 415 type, 502 upstream/persistence and 503 unavailable. Client UI does not echo structured validation input. No raw upstream/private content is logged by application error handlers.

Analysis job states: queued/running/complete/error. Analysis run states: running/complete/error/blocked. `complete` means the recorded coverage completed, not human approval. Transfer event `attempting` is intent, `succeeded` means provider returned valid output, `failed` can still mean the provider received a request. A crash can leave delivery unknown. UI refreshes active jobs every three seconds with cleanup on unmount/workspace change.

## Public configuration and optional website analytics

`GET /api/public/config` returns only public operator/contact values, CAPTCHA public site key/requirement and analytics availability. No private keys are serialized. `POST /api/public/events` accepts only event=page_view/cta_click, an allowlisted public path (/, /privacy, /terms, /contact), and consent_version=1. Extra fields/private paths are rejected. It requires configured optional analytics/server persistence, an allowed Origin and per-process rate limits, honors DNT/GPC and returns 204 on accepted/no-track requests. Browser code also requires valid, unexpired consent and never emits workspace/auth URLs. Website metrics are server-only records, not unique visitor counts. Actual collection is unavailable until the server secret is configured. Production /ready also fails for missing legal/domain/CAPTCHA setup.
